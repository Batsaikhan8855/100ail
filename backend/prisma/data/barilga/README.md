# barilga.mn каталогийн импорт

`https://www.barilga.mn/p/` дээрх нийтийн бүтээгдэхүүний каталогийг татаж
barilgaHUB-ын мэдээллийн санд оруулах гурван алхамт урсгал.

## 1. Өгөгдөл татах

```bash
cd backend/prisma/data/barilga
python3 scrape.py     # ангилал + жагсаалтын бүх хуудас
python3 details.py    # бүтээгдэхүүн бүрийн дэлгэрэнгүй
```

Эдгээр нь дараах файлуудыг үүсгэнэ:

| Файл | Агуулга | Repo-д |
|---|---|---|
| `categories.json` | cid → ангиллын нэр | ✗ түр файл |
| `listing.json` | жагсаалтын хуудаснуудаас цуглуулсан ID, нэр, үнэ, thumbnail | ✗ түр файл |
| `details.jsonl` | дэлгэрэнгүй татацын түүхий гаралт (мөр мөрөөр) | ✗ түр файл |
| `products.json.gz` | **импортод ашиглагдах эцсийн өгөгдөл** | ✓ |

Дэлгэрэнгүй татах хэсэг удаан (эх сайт ~2 хүсэлт/сек орчим өгдөг, хааяа
timeout болдог). `details.py` нь `details.jsonl` руу мөр мөрөөр бичдэг тул
**тасарсан үед дахин ажиллуулахад зөвхөн дутуу ID-г татна**. Төгсгөлд нь
`products.json.gz`-г дахин угсарна.

## 2. Зураг татах

```bash
python3 images.py
```

`img.barilga.mn` нь `?d=0` параметргүй хүсэлтийг 403-аар хаадаг, түүнтэй
хүсэлтэд ч огт хариу өгдөггүй (гаднаас холбохыг зориудаар хаасан) тул
зургийг `backend/media/barilga/` дор буулгаж авна. Дахин ажиллуулахад
татсан файлыг алгасна.

| Орчны хувьсагч | Анхдагч | Утга |
|---|---|---|
| `IMAGE_MAX_PER_PRODUCT` | `5` | Бүтээгдэхүүн бүрээс хэдэн зураг татах |
| `IMAGE_MAX_EDGE` | `500` | Урт талыг энэ px рүү багасгана (macOS `sips`) |
| `MEDIA_DIR` | `media` | `backend/`-ээс тоологдох медиа сангийн зам |

`backend/media/` нь `.gitignore`-д байгаа — түүхий зураг repo-д ордоггүй.

## 2.5. Зургийг WebP болгож CDN-д бэлдэх

```bash
brew install webp     # cwebp хэрэгтэй
python3 webp.py       # ~30 секунд
```

Түүхий зураг (394MB, ихэнх нь PNG) нь production-д хэтэрхий том тул
WebP болгож **frontend-ийн `public/` дор** байршуулна. Тэндээс Vercel-ийн
CDN өгнө — API-ийн instance нь 5000 гаруй статик файл өгөхөд
тохиромжгүй.

Гаралт:

| Зам | Агуулга | Repo-д |
|---|---|---|
| `frontend/storefront/public/media/barilga/<хэш>.webp` | зураг өөрөө (67MB) | ✓ |
| `backend/prisma/data/barilga/images.json.gz` | импортын жагсаалт (104KB) | ✓ |

**Жагсаалт яагаад хэрэгтэй вэ:** импорт нь үүлэн орчинд ажилладаг ба тэнд
зургийн файл байдаггүй (`.dockerignore` нь `backend/media`-г хасдаг). Тиймээс
`import-barilga.ts` нь `fs.existsSync`-ийн оронд энэ жагсаалтаас аль зураг
CDN дээр байгааг мэднэ.

| Орчны хувьсагч | Анхдагч | Утга |
|---|---|---|
| `WEBP_MAX_EDGE` | `440` | Урт талын px |
| `WEBP_QUALITY` | `76` | WebP-ийн чанар |
| `WEBP_WORKERS` | `8` | Зэрэг ажиллах процесс |

Хэмжээ нь **Vercel-ийн Hobby тарифын 100MB статик хязгаарт** багтах ёстой.
Бүх 5,451 зургийн бодит нийт хэмжээ:

| Тохиргоо | Нийт |
|---|---|
| 500px q80 | 107MB — хязгаараас давна |
| **440px q76** | **67MB** — анхдагч |
| 400px q74 | 56MB |

Харагдах хамгийн том хайрцаг 288×228 CSS px (`product-detail.tsx`) тул
440px нь retina дэлгэцэнд хангалттай.

### Зураг өгөх хаяг

Railway дээр дараах хувьсагчийг тавина:

```
S3_PUBLIC_URL=https://100ail.vercel.app/media
```

`StorageService.publicUrl` нь `barilga/<хэш>.webp` түлхүүрийг үүнтэй
залгаж `https://100ail.vercel.app/media/barilga/<хэш>.webp` болгоно.
Файлын нэр нь агуулгын хэш тул `next.config.ts` дотор нэг жилийн
`immutable` кэш тавьсан.

## 3. Мэдээллийн санд импортлох

```bash
cd backend
npm run db:import:barilga                 # үлдэгдэл 0-оор
npm run db:import:barilga -- --stock=50   # туршилтын үлдэгдэл оноох
```

Импорт нь **давтан ажиллуулахад аюулгүй**: бүтээгдэхүүнийг `barilga-<id>`
slug-аар нь таньж шинэчилдэг тул seed өгөгдөл болон захиалгад орсон
саналуудад хүрэхгүй.

## 4. Seed-тэй хамаарал

`npm run db:seed` нь каталог үүсгэдэггүй (ангилал, нийлүүлэгч, хэрэглэгч,
баннер л үүснэ) — бараа энэ импортоос ирнэ. Тестийн 33 зохиомол барааг
`npm run db:seed:demo` үүсгэнэ.

### Тэмдэглэл

- Эх сайт бүтээгдэхүүн бүрийн **нийлүүлэгчийг харуулдаггүй** тул бүх санал
  `barilga-mn` гэсэн нэг эх сурвалжийн нийлүүлэгч дээр үүснэ.
- **Үлдэгдлийн мэдээлэл эх сайтад байхгүй** тул анхдагчаар 0. Зохиомол тоо
  оруулахгүйн тулд `--stock` тодорхой заагаагүй бол 0 хэвээр үлдэнэ.
- Үнэгүй зарласан бараа санал үүсгэхгүй бөгөөд `active: false` болно
  (каталогт харагдахгүй).
- Галерейд ихэвчлэн ганц 900×900 зураг байдаг. Тайлбар (`descriptionHtml`)
  дотор нэмэлт гэрэл зураг байвал (~17% бараанд) галерейд залгагдана —
  `scrape.py: description_images`, бараа тутам 4 хүртэл.
- Зураг нь зөвхөн `webp.py`-аар бэлдсэн `barilga/<хэш>.webp` түлхүүрээр
  холбогдоно. Эх сайт руу hotlink хийхийг **зориудаар хассан** — тэр CDN
  хариу өгдөггүй тул зураг ачаалагдахгүй мөнхөд хүлээдэг байсан. Зураггүй
  бараа (~15%) нь `ProductArt`-ийн вектор дүрслэлээр харагдана.
