# barilga.mn каталогийн импорт

`https://www.barilga.mn/p/` дээрх нийтийн бүтээгдэхүүний каталогийг татаж
100 Айл-ын мэдээллийн санд оруулах гурван алхамт урсгал.

## 1. Өгөгдөл татах

```bash
cd backend/prisma/data/barilga
python3 scrape.py     # ангилал + жагсаалтын бүх хуудас
python3 details.py    # бүтээгдэхүүн бүрийн дэлгэрэнгүй
```

Эдгээр нь дараах файлуудыг үүсгэнэ:

| Файл | Агуулга | Repo-д |
|---|---|---|
| `categories.json` | cid → ангиллын нэр | ✗ түр файл |
| `listing.json` | жагсаалтын хуудаснуудаас цуглуулсан ID, нэр, үнэ, thumbnail | ✗ түр файл |
| `details.jsonl` | дэлгэрэнгүй татацын түүхий гаралт (мөр мөрөөр) | ✗ түр файл |
| `products.json.gz` | **импортод ашиглагдах эцсийн өгөгдөл** | ✓ |

Дэлгэрэнгүй татах хэсэг удаан (эх сайт ~2 хүсэлт/сек орчим өгдөг, хааяа
timeout болдог). `details.py` нь `details.jsonl` руу мөр мөрөөр бичдэг тул
**тасарсан үед дахин ажиллуулахад зөвхөн дутуу ID-г татна**. Төгсгөлд нь
`products.json.gz`-г дахин угсарна.

## 2. Зураг татах

```bash
python3 images.py
```

`img.barilga.mn` нь `?d=0` параметргүй хүсэлтийг 403-аар хаадаг бөгөөд
гаднаас холбох (hotlink) нь найдваргүй тул зургийг `backend/media/barilga/`
дор буулгаж авна. Дахин ажиллуулахад татсан файлыг алгасна.

| Орчны хувьсагч | Анхдагч | Утга |
|---|---|---|
| `IMAGE_MAX_PER_PRODUCT` | `3` | Бүтээгдэхүүн бүрээс хэдэн зураг татах |
| `IMAGE_MAX_EDGE` | `500` | Урт талыг энэ px рүү багасгана (macOS `sips`) |
| `MEDIA_DIR` | `media` | `backend/`-ээс тоологдох медиа сангийн зам |

`backend/media/` нь `.gitignore`-д байгаа — зураг repo-д ордоггүй.

## 3. Мэдээллийн санд импортлох

```bash
cd backend
npm run db:import:barilga                 # үлдэгдэл 0-оор
npm run db:import:barilga -- --stock=50   # туршилтын үлдэгдэл оноох
```

Импорт нь **давтан ажиллуулахад аюулгүй**: бүтээгдэхүүнийг `barilga-<id>`
slug-аар нь таньж шинэчилдэг тул seed өгөгдөл болон захиалгад орсон
саналуудад хүрэхгүй.

### Тэмдэглэл

- Эх сайт бүтээгдэхүүн бүрийн **нийлүүлэгчийг харуулдаггүй** тул бүх санал
  `barilga-mn` гэсэн нэг эх сурвалжийн нийлүүлэгч дээр үүснэ.
- **Үлдэгдлийн мэдээлэл эх сайтад байхгүй** тул анхдагчаар 0. Зохиомол тоо
  оруулахгүйн тулд `--stock` тодорхой заагаагүй бол 0 хэвээр үлдэнэ.
- Үнэгүй зарласан бараа санал үүсгэхгүй бөгөөд `active: false` болно
  (каталогт харагдахгүй).
- Зураг татсан бол `barilga/<файл>` түлхүүрээр локалаас, татаагүй бол эх
  сайтын хаягаар нь холбогдоно (`StorageService.publicUrl` бүтэн http
  хаягийг дамжуулдаг).
