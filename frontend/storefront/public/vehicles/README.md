# Хүргэлтийн машины гэрэл зураг

Сагсны машины сонголтод (`components/vehicle-art.tsx`) харагдана. Файлын нэр
нь `backend/src/common/logistics/logistics.ts` дахь `VEHICLES`-ийн `id`-тай
таарна.

| Файл | Машин | Даац |
|---|---|---|
| `porter.jpg` | Портер | 1 т |
| `truck-3.jpg` | 3 тонны ачааны машин | 3 т |
| `truck-5.jpg` | 5 тонны ачааны машин | 5 т |
| `truck-10.jpg` | 10 тонны ачааны машин | 10 т |
| `truck-20.jpg` | 20 тонны чиргүүл | 20 т |

Файл байхгүй бол вектор дүрслэл (`vehicle-art.tsx`) автоматаар харагдана —
солихдоо зөвхөн файлаа солино, код өөрчлөх шаардлагагүй.

Зөвлөмж: урт тал 640px, `object-cover`-оор тайрагдана.

## Одоогийн зургууд

Эдгээр нь **түр зуурын** зураг — Wikimedia Commons-оос авсан нээлттэй
лицензтэй гэрэл зураг. Тээврийн хамтрагчтайгаа гэрээ хийсний дараа өөрсдийн
машиныхаа зургаар солих нь зүйтэй (брэндийн бичиглэлгүй, цэвэр дэвсгэртэй).

Лиценз нь **тайлбар шаарддаг** тул солих хүртэл доорх мэдээллийг хадгална.
Тайлбарыг хуудсанд харуулах шаардлагатай бол `ATTRIBUTION.md`-г ашиглана.

# Хэмжээсийн зураг

Сагсны «Машины хэмжээ» хэсэгт харагдана (`components/vehicle-blueprint.tsx`).
Файлын нэр нь `<id>-dimensions.png` (эсвэл `.jpg`). Хэмжээсийн зураг бол
зураасан зураг тул **PNG нь илүү** — JPEG нарийн шугамын эргэн тойронд
бохир толбо үлдээдэг. Хоёулаа байвал PNG-г сонгоно.

| Файл | Машин | Төлөв |
|---|---|---|
| `porter-dimensions.png` | Портер | Байгаа |
| `truck-3-dimensions.png` | 3 тонны ачааны машин | Байхгүй |
| `truck-5-dimensions.png` | 5 тонны ачааны машин | Байхгүй |
| `truck-10-dimensions.png` | 10 тонны ачааны машин | Байхгүй |
| `truck-20-dimensions.png` | 20 тонны чиргүүл | Байхгүй |

Файл байхгүй бол `VehicleBlueprint` вектор зураг өөрөө зурагдана —
`logistics.ts` дахь `VehicleSpec`, `VehicleBed`, `shape`-ийг ашиглаж дөрвөн
харагдацыг зурна. Вектор нь ямар ч хэмжээнд тод, эрхийн асуудалгүй тул
бодит зураг олдох хүртэл бүрэн хувилбар болно.

⚠️ `porter-dimensions.png` нь **Hyundai-н каталогийн зураг** — үйлдвэрийн
эрхтэй бүтээл. Худалдааны хэрэглээнд оруулахын өмнө зөвшөөрөл авах, эсвэл
өөрсдийн машиныг хэмжиж зурсан зургаар солих шаардлагатай.
